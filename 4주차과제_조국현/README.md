# 4주차 과제 - 신입사원 프로젝트

이 저장소에는 4주차 과제로 진행한 두 프로젝트가 **독립적으로** 구현되어 있습니다.
각 프로젝트는 3주차 코드 리뷰 피드백(상태 관리, Magic Number 제거, 이벤트 위임,
`innerHTML` 대신 `textContent` 사용 등)을 반영했습니다.

## 프로젝트 목록

| 프로젝트 | 설명 | 경로 |
|---|---|---|
| Project#1 To-Do-List | 일정 추가/삭제 기능 | [결과물 보기](./4주차과제_조국현/todo-list/) |
| Project#2 회원가입 | 아이디 중복 체크, 비밀번호 정상성 체크 | [결과물 보기](./4주차과제_조국현/signup/) |

각 프로젝트의 상세 요구사항, 실행 방법, 디렉터리 구조는 프로젝트 폴더 안의 `README.md`를 참고해주세요.

## 실행 방법 (공통)
두 프로젝트 모두 별도의 빌드/설치 과정 없이 순수 HTML/CSS/JavaScript로 동작합니다.
각 폴더의 `index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.
