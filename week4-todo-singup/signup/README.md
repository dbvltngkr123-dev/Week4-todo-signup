# 회원가입 (Signup)

## 프로젝트 개요
Vanilla JavaScript로 구현한 회원가입 폼입니다. 백엔드 없이 mock 데이터로 아이디 중복 확인과
비밀번호 정합성(강도) 체크 기능을 구현했습니다.

## 기능 설명 (Function Requirement)
- **FR1**: 아이디 중복 체크가 됩니다. ('중복 확인' 버튼 클릭 시 mock DB와 비교)
- **FR2**: 비밀번호 정상성(강도) 체크 기능이 있습니다.
  - 나만의 규칙: **8~20자**, **영문 / 숫자 / 특수문자(!@#$%^&*) 각 1개 이상 포함**

## 설치 방법
별도의 설치 과정이 필요 없습니다. `index.html` 파일을 브라우저로 열면 바로 실행됩니다.

```bash
cd signup
open index.html   # 또는 더블 클릭으로 브라우저에서 열기
```

## 사용 방법
1. 아이디를 입력하고 '중복 확인' 버튼을 클릭합니다. (영문/숫자 4~12자)
2. 비밀번호를 규칙에 맞게 입력하면 실시간으로 유효성 메시지가 표시됩니다.
3. 비밀번호 확인란에 동일한 비밀번호를 입력합니다.
4. '가입하기' 버튼을 누르면 유효성 검사를 통과한 경우에만 가입이 완료됩니다.

> 테스트용으로 이미 등록된 것으로 취급되는 아이디: `mentor01`, `cocento`, `admin`

- HTML5
- CSS3 (CSS Variables)
- Vanilla JavaScript (ES6+)

## 코드 설계 포인트 (3주차 피드백 반영)
- `state` 객체로 중복 확인 여부, 사용 가능 여부 등을 한 곳에서 관리합니다.
- 아이디/비밀번호 길이, 정규식 등은 이름 있는 상수로 선언해 Magic Number를 지양했습니다.
- 메시지 출력은 `textContent`만 사용해 XSS 위험을 차단했습니다.
- DOM 조회는 Optional Chaining(`?.`)으로 요소 존재 여부를 고려했습니다.
- 검증(validate) / 상태 갱신 / 화면 출력(setFieldMessage) 함수를 역할별로 분리했습니다(SRP).
- 아이디를 중복 확인한 뒤 다시 수정하면 확인 상태를 무효화하여, 검증되지 않은 아이디로
  가입되지 않도록 처리했습니다.

## 향후 개선 사항
- 실제 서버 API와 연동한 아이디 중복 확인
- 비밀번호 강도를 단계별(약함/보통/강함)로 시각화
- 아이디/비밀번호 입력 시 디바운스 적용
