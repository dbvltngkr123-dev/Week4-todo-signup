# To-Do List

## 프로젝트 개요
Vanilla JavaScript로 구현한 할 일 관리(To-Do List) 웹 애플리케이션입니다.
3주차 코드 피드백(상태 관리, Magic Number 제거, 이벤트 위임, innerHTML 대신 textContent 사용, CSS 변수 기반 테마 전환)을 반영하여 작성했습니다.

## 기능 설명 (Function Requirement)
- **FR1**: 일정을 추가할 수 있습니다. (입력 후 Enter 또는 '추가' 버튼)
- **FR2**: 일정을 삭제할 수 있습니다. (각 항목의 '삭제' 버튼)

### 추가 구현 기능
- **완료 체크(토글)**: 체크박스로 완료 여부를 표시하며, 완료 항목은 취소선으로 표시됩니다.
- **할 일 수정**: '수정' 버튼을 누르면 인라인으로 텍스트/마감일/우선순위를 바꿀 수 있습니다. (Enter=저장, Esc=취소)
- **중복 일정 등록 방지**: 공백/대소문자를 무시했을 때 이미 등록된 문구와 같으면 추가·수정이 거부됩니다.
- **필터 & 남은 개수 표시**: 전체/진행중/완료로 목록을 필터링하고, 완료되지 않은 항목 수를 표시합니다.
- **마감일 / 우선순위**: 일정마다 마감일과 우선순위(낮음/보통/높음)를 지정할 수 있고, 마감일이 지난 미완료 항목은 배지가 강조 표시됩니다.
- **드래그로 순서 변경**: 항목 왼쪽의 손잡이(⋮⋮)를 드래그해 순서를 바꿀 수 있습니다.
- **다크모드 토글**: 우측 상단 버튼으로 라이트/다크 테마를 전환합니다. (CSS 변수 재정의 방식)

## 설치 방법
별도의 설치 과정이 필요 없습니다. `index.html` 파일을 브라우저로 열면 바로 실행됩니다.

```bash
cd todo-list
open index.html   # 또는 더블 클릭으로 브라우저에서 열기
```

## 사용 방법
1. 입력창에 할 일을 입력하고, 필요하면 우선순위와 마감일을 지정합니다. (최대 100자, 이미 등록된 문구는 추가 불가)
2. '추가' 버튼을 클릭하거나 Enter를 누르면 목록에 추가됩니다.
3. 체크박스를 클릭하면 완료 상태로 표시됩니다(취소선).
4. '수정' 버튼을 누르면 텍스트/마감일/우선순위를 바로 고칠 수 있습니다. (Enter=저장, Esc=취소)
5. '삭제' 버튼을 클릭하면 해당 항목이 제거됩니다.
6. 상단 필터 탭(전체/진행중/완료)으로 목록을 좁혀볼 수 있습니다.
7. 항목 왼쪽의 ⋮⋮ 손잡이를 드래그하면 순서를 바꿀 수 있습니다.
8. 우측 상단 🌙/☀️ 버튼으로 다크모드를 켜고 끌 수 있습니다.

## 기술 스택
- HTML5 (Drag and Drop API)
- CSS3 (CSS Variables, 다크모드 테마)
- Vanilla JavaScript (ES6+)

## 코드 설계 포인트 (3주차 피드백 반영)
- 전역 변수 대신 `state` 객체 하나로 데이터를 관리합니다. (드래그 진행 상태처럼 렌더링과 무관한 값만 별도 변수로 분리)
- 삭제/수정/토글 버튼마다 리스너를 등록하지 않고, 목록 컨테이너에 이벤트 위임을 적용했습니다.
- `innerHTML` 대신 `createElement` + `textContent`로 DOM을 구성해 XSS 위험을 줄였습니다.
- 글자 수 제한, 메시지 노출 시간, 우선순위 값 등은 이름이 있는 상수로 관리하고 Magic Number를 지양했습니다.
- 다크모드는 `:root` CSS 변수를 `html[data-theme="dark"]` 선택자로 재정의하는 방식으로 구현해, 색상을 하드코딩하지 않고 테마 전환이 가능하도록 했습니다.
